# TerraForge v0.1.4 — Mac distributions

This release publishes the supplied Intel and Apple Silicon Mac applications. Both archives are preserved unchanged and include their matching Java runtime and native libraries.

Choose Intel for x86_64 Macs or Apple Silicon for arm64 Macs. Extract the ZIP to obtain TerraForge.app.

The distribution release is v0.1.4. The supplied app bundles retain their original internal 0.1.0 labels. No Java source was supplied with these Mac packages; correspondence to repository Java source has not been verified. macOS startup and GPU rendering were not tested on this Ubuntu host. ZIP integrity checks passed; SHA-256 checksums are attached.

Linux users can continue using the v0.1.3 Linux downloads.
